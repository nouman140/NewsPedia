# 📰 NEWSPEDIA - Your Daily News Hub

![React](https://img.shields.io/badge/React-19.0-blue?logo=react)
![Tailwind CSS](https://img.shields.io/badge/Tailwind-3.0-38B2AC?logo=tailwind-css)
![Vite](https://img.shields.io/badge/Vite-5.0-646CFF?logo=vite)
![License](https://img.shields.io/badge/License-MIT-green)

**NEWSPEDIA** is a modern, responsive news aggregation web app that fetches real-time headlines from 7 different categories using the NewsAPI. Built with React 19 and Tailwind CSS, it provides a seamless reading experience with search functionality, category filtering, and beautiful UI.

---

## ✨ Features

| Feature                       | Description                                                           |
| ----------------------------- | --------------------------------------------------------------------- |
| 📰 **7 News Categories**      | Business, Entertainment, General, Sports, Science, Technology, Health |
| 🔍 **Search News**            | Search any topic using the everything endpoint                        |
| 🎨 **Modern UI**              | Beautiful gradient backgrounds with glassmorphism effects             |
| 📱 **Fully Responsive**       | Works perfectly on mobile, tablet, and desktop                        |
| ⚡ **Fast Performance**       | Built with Vite for lightning-fast builds                             |
| 🖼️ **Image Fallback**         | Graceful handling of broken image URLs                                |
| ⏳ **Loading States**         | Smooth loading animations and skeletons                               |
| ❌ **Error Handling**         | Proper error messages for API failures (429, 426, etc.)               |
| 🔄 **Auto-retry**             | Exponential backoff for rate-limited requests                         |
| 📌 **Route-based Navigation** | React Router for seamless page transitions                            |

## 🛠️ Tech Stack

### Frontend

- **React 19** - UI library
- **React Router DOM v6** - Navigation
- **Tailwind CSS** - Styling
- **Vite** - Build tool

### APIs

- **currentapi** - News data source
